# 海风骑行

一幅可直接使用和编辑的原创 SVG 插画：系着围巾的鹈鹕骑着珊瑚红色自行车，穿过温暖的海边风景。

- `pelican-cycling.svg`：完整矢量源文件，画布为 1440 × 1080，可无损缩放。
- `pelican-cycling.png`：2880 × 2160 高清预览。

用浏览器打开 SVG 即可查看；也可导入 Figma、Illustrator 或 Inkscape 编辑。SVG 不依赖外部图片、字体或脚本，含中文结构注释和无障碍标题、描述。

## 修改方式

- 在 `defs` 中调整公共样式、渐变和可复用的车轮。
- 按各个带 `id` 的分组修改背景、自行车、身体、围巾、腿、翅膀和长喙。
- 修改根元素的 `width`、`height` 可调整输出尺寸；保留 `viewBox` 可保持构图与比例。
- 若要透明背景，可隐藏 `background` 和 `ground` 分组。
